# SportOrganiza

Plataforma web para la gestión y organización de torneos deportivos.

## Funcionalidades

- Gestión de equipos.
- Registro de jugadores.
- Organización de torneos.
- Gestión de inscripciones.
- Administración de partidos.

## Tecnologías

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Proyecto

Desarrollado como proyecto formativo del programa Análisis y Desarrollo de Software del SENA.
